# Personal Woodshed tooling overlay

This file belongs only on the personal contribution fork's `agents-overlay`
branch or in a locally excluded worktree. The organization product owns the
practice contract, catalog, dispatcher, source, and tests.

Use the `woodshed-session` skill as a thin adapter to `just capabilities` and
`just session`. Guide time, activity, feedback, and workspace choices through
that interface. Respect explicit readiness before a study transition. The
learner owns candidate source and test edits; saved work is practice data.
Record outcomes only through successful canonical commands.

`provenance/legacy` preserves former provider personas and generators for
migration evidence. Do not restore those as active routing or run their old
generation recipes. Configure and authenticate only the tools the operator
selects; keep credentials outside git and product pull requests.
